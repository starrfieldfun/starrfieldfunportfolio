DESIGN RULE
-----------
The homepage is the trailer. The rest of the portfolio is the full story.
The homepage therefore hooks, previews, and hands visitors into deeper pages
instead of reproducing those pages in full.

KEY BEHAVIOUR
-------------
- Opening Absolute Cinema remains in place.
- Scenes 05–10 continue the movie through Starr / Work / Services / Method /
  Photography / Final handoff.
- Normal scrolling remains enabled; there is no scroll-jacking.
- Desktop scenes use sticky full-screen stages and scroll-driven parallax.
- A persistent START A PROJECT link lets ready clients go directly to Contact.
- Final scene explicitly hands visitors into Work, Contact, About, or Services.
- Scroll reveal uses movement + opacity only. No blur is added.
- Mobile falls back to normal-flow scenes for readability and performance.
- Reduced-motion users receive a static, accessible version.
